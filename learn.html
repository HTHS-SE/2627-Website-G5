Creating a Basic Neural Network



-Adapted from PyTorch docs-

In the modern world, building a neural network program has become increasingly facilitated for beginners in the field of machine learning and artificial intelligence. In this tutorial, we will detail the process in creating your very first neural network with the use of the python library PyTorch.


Getting started


Assuming the installation of a suitable python version is complete, pytorch and the corresponding torchvision libraries can be installed through the pip package manager from python in the terminal with the following command:

pip install torch torchvision

It is important to install a correct version of pytorch, given that GPU accelerators may require the use of NVIDIA's CUDA toolkit, more on which can be found here. Otherwise, CPUs can be used to train neural network programs, albeit at a pace slower than that of GPUs by a considerable factor.


When finished, import the following classes into the python script to allow for the use of pytorch and os libraries:


import os
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

Class Initialization


Neural networks are conventionally built in the format of a class. For the purposes of this introduction, we will use linear NN layers to build a simple MNIST neural network. Since the MNIST dataset consists of images with 784 pixels each, and we want the return of the network to be a 10-class vector of digit probabilities, we utilize several linear layers to accomplish this goal:

class NeuralNetwork(nn.Module):
    def __init__(self):
        super(NeuralNetwork, self).__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
        nn.Linear(28*28, 512),
    nn.ReLU(),
    nn.Linear(512, 512),
    nn.ReLU(),
    nn.Linear(512, 10)
   )

  def forward(self, x):
    logits = self.linear_relu_stack(x)
    logits = self.linear_relu_stack(self.flatten(x))
    return logits


We additionally write a forward function in the neural network class to allow for the forward pass of data. Flattens are used in order to flatten 28x28 pixel images into 784-by-1 vectors capable of being fed into the linear layers. The function takes in a tensor (generalization of scalars, vectors, etc) which is then used and processed through the network. We will assume the tensor holds a "requires_grad" parameter of "true" for convenient backpropagation of gradients, which will be used later on.



Passing Data Through the Model


To pass data through the model, simply initialze a torch tensor of size 1-by-28-by-28 with requires_grad=True and proper device initializations to begin with. Afterwards, pass through the tensor with a call through the model, which is also to be initialized using the neural network class defined above. Backpropagation is done with the nn.backward() command on calculated loss values from the logits returned by the model, which allows us to extract gradients in a seamless manner, and parameters are updated with the optimizer.step() function that follows:

model = NeuralNetwork().to(device)
x = torch.rand(1, 28, 28, requires_grad=True, device=device)
logits = model(x)
loss = loss_fn(logits, y)

Congratulations! You have now built a rudimentary neural network model in pytorch, capable of taking in vector datasets which is also capable of backpropagation on a general level!
