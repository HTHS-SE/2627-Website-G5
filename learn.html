Creating a Basic Neural Network

Adapted from PyTorch documentation

In the modern world, building a neural network program has become increasingly accessible to beginners in machine learning and artificial intelligence. In this tutorial, we will explain the process of creating your very first neural network using the Python library PyTorch.

Getting Started

Assuming that a correct version of Python is already installed, PyTorch and the corresponding Torchvision library can be installed through the pip package manager using the following command in the terminal:

pip install torch torchvision

It is important to install a compatible version of PyTorch. GPU acceleration may require NVIDIA's CUDA toolkit, more information about which can be found here. Otherwise, CPUs can be used to train neural networks, although training may be considerably slower.

Once installation is complete, import the following modules into your Python script to use PyTorch and its associated data utilities:

import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

Class Initialization

Neural networks are conventionally implemented using classes. For this introduction, we will use linear layers to build a simple neural network that can classify images from the MNIST dataset. Since MNIST images contain 784 pixels each, and the network must produce ten output values corresponding to the ten possible digits, we use several linear layers to accomplish this goal.

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28 * 28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits

We additionally define a forward() function in the neural network class to specify how input data passes through the model. The flattening operation converts each 28-by-28 image into a vector containing 784 values, allowing it to be processed by the linear layers. The network returns ten logits, which represent unnormalized scores for the possible digit classes.

During training, these logits can be compared with the correct labels using a loss function such as nn.CrossEntropyLoss(). The loss measures how far the model's predictions are from the expected answers and provides the information needed to improve the network's parameters.

Passing Data Through the Model

To pass data through the model, initialize the neural network and create an input tensor with the appropriate dimensions. For a batch containing one MNIST image, the input shape is (1, 1, 28, 28), representing the batch size, number of channels, image height, and image width.

device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)

model = NeuralNetwork().to(device)
x = torch.rand(1, 1, 28, 28, device=device)
logits = model(x)

The input tensor is passed to the model, which returns ten logits. During training, the correct label is used to calculate the loss. Backpropagation computes gradients, and an optimizer updates the model's parameters to improve its predictions.

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)

y = torch.tensor([3], device=device)
optimizer.zero_grad()
logits = model(x)
loss = loss_fn(logits, y)
loss.backward()
optimizer.step()

This example demonstrates a single training step using a randomly initialized input and a sample label. A complete training program would repeat this process over batches of real images and their corresponding labels for multiple epochs.

Congratulations! You have now explored the basic structure of a neural network in PyTorch, including its layers, forward pass, loss calculation, and parameter updates.
